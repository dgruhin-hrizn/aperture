# v0.8.0-dev.8.2 — Media actions and synopses in Encore

Encore’s movie and series cards now show a two-line synopsis when metadata is available. Single results use the chat width for a poster, metadata, and a row of touch-friendly action icons. Results in carousels offer the same media actions through a menu.

- Play a library title or open its details.
- Rate a movie or series from the card.
- Add or remove a series from your Watching list.
- Create a private Emby playlist starting with a library movie. Encore shows the proposed playlist and applies it after approval.

Cards from saved conversations also get the action buttons when they have the corresponding links. Run the search again to get a synopsis on a result saved before this update.

Pull `ghcr.io/dgruhin-hrizn/aperture:0.8.0-dev.8.2` or refresh the development image and recreate the app container with the existing configuration. No database migration is required.
