# Aperture 1.0.1-dev.2

Search, autocomplete, search filters, Similar titles, and graph exploration now verify the viewer's current Emby catalog. Search handles punctuation, ranks exact and alternate title matches first, and can add matches from the configured semantic provider. Title search and autocomplete verify a shortlist with Emby. The page shows title results while semantic results load.

Encore verifies exact details and release or discovery candidates with targeted Emby reads. Movie and TV recommendations can use highly rated titles and saved interests to make starter picks when watch history does not provide a usable profile.

Admin Gap Analysis preserves the last successful movie scan and can check the released seasons and episodes of an imported Emby series. It compares TMDb season data with the current Emby inventory, including files that cover multiple episodes. Manual Seerr requests check current status and prevent overlapping submissions. If the outcome of a submission is uncertain, the request stays pending while Aperture checks for confirmation.

Emby episode sync retries a failed page at the same offset with a smaller size and checks scan completeness before stale cleanup. The Jellyfin library import accepts the current virtual-folder identifier and locations.

Restores stop when the requested safety backup fails and apply the backup in a PostgreSQL transaction. Allow temporary disk space for the decompressed SQL. The restore path supports the bundled PostgreSQL 17 client and PostgreSQL 16 server.

PRs run the validation suite before merge. Both release architectures smoke test their image digests before publication, and published version tags cannot be overwritten by the workflow. The development channel follows a published development tag.

Run `node scripts/recommendation-outcomes.mjs 30` with `DATABASE_URL` set to see aggregate playback after saved picks. This measures observed playback, and TV completion covers the currently imported regular episodes.

There are no new database migrations. The development image is `ghcr.io/dgruhin-hrizn/aperture:1.0.1-dev.2`.
