# Aperture 0.7.11 development release

## What users will see

- AI Picks records when a title was selected for each account. Movies and shows that were recently suggested take a break. After the cooldown, only a limited number of returning titles can appear in a list.
- Movie recommendations use ratings on Aperture’s ten-point scale. Themes from TMDb and MDBList can lift a movie when they recur in recent viewing. The movie algorithm can reserve one fifth of its requested picks for highly rated films outside the viewer’s most-watched genres.
- On Emby, admins can publish separately named TV picks and can opt into private native playlists. Native playlists reference original Emby items, so a playback check-in can update the original title. A user’s Emby client and any external Wrapped exporter determine how activity is displayed and counted.

## What admins can configure

| Setting | Where to find it | Behavior |
| --- | --- | --- |
| Repeat suggestion cooldown | Settings → AI Recommendations → Algorithm | Separate movie and TV settings, both 180 days by default |
| Emby TV recommendation groups | Settings → Setup → Media Server → Libraries → TV Shows | Group one or more enabled source libraries into named outputs |
| Media server output | Settings → AI Recommendations → Output | Choose a generated library, the private Emby playlist preview, or Off independently for movies and TV |
| Import Media Server | Admin → Jobs → Global | Import users, catalog, and watch history without AI tokens or publication |

Save any desired settings, run the relevant recommendation-generation job, and then run the corresponding library sync to publish. Generation can use model tokens. Library sync publishes saved results.

Numeric Emby source IDs are now accepted by the source-library toggle. Generated Emby outputs are checked against the viewer’s source access and the exact item paths. Aperture withholds library files if another active non-admin account can access the output. The native playlist preview requires each recipient to sign into Aperture with Emby and checks the playlist’s audience before adding original items.

## Upgrade and validation

The versioned development image is `ghcr.io/dgruhin-hrizn/aperture:0.7.11-dev.3`. It is available for Linux AMD64 and ARM64. Use the versioned tag to reproduce this build.

Back up PostgreSQL and uploaded artwork before replacing the app container. Keep the existing database and mounts. Migrations 0115–0117 backfill suggestion history from retained completed runs and add storage for groups and managed playlists. No manual data entry is needed for these migrations.

The image was tested against an existing 0.7.10 database. The Emby 4.10.2 checks covered private playlist visibility, original item references, cleanup after access revocation, and playback reporting to the original movie. External Wrapped exporters and every Emby client remain outside that validation. The earlier dev.1 build was superseded after live Emby testing found permission and playlist API compatibility issues.

## Release dialogs (dev.3)

The updated interface shows one release dialog at the next authenticated visit. Admins see configuration and jobs guidance. Regular users see the changes to recommendations and playback. Dismissal is saved per account and role in the user’s preferences.

## Pin to Emby Home (dev.4)

Open **AI Picks → Emby Home** to pin a private Aperture-managed playlist as a Home section. Unpin removes only the section Aperture created and preserves the playlist. Shelves created directly in Emby stay under Emby’s control. This build adds migration 0118 to record which sections Aperture owns.

## Local model explanations

Movie and TV explanation batches now accept fenced JSON and recover from apostrophes escaped by local models such as Qwen. Structurally invalid responses still use the existing fallback. Generated movie and TV library descriptions use the recipient’s effective AI language for the headings above the explanation and overview. Run recommendation generation to refresh explanations and library sync to rewrite existing descriptions.

## Tonight (dev.5)

The new **Tonight** page combines live Continue Watching from Emby with up to three saved AI Picks. Open a pick or in-progress title directly in Emby. The page uses existing recommendations and requires no new settings, model calls, or Home screen changes. This release also includes the local-model explanation and translated-heading fixes above.

## Not tonight (dev.6)

Hide a Tonight pick for 12 hours and get the next eligible saved recommendation immediately when one is available. The change is scoped to Tonight and uses no model tokens. Migration 0119 stores these temporary dismissals separately from your taste profile and settings.
