# Aperture 1.0.3

Encore opens as a chat agent over the current page. Use the floating desktop button, the Encore navigation action, or the center mobile dock button. Desktop starts with a compact panel that can expand into a larger modal. Close it to return to the page underneath. The same conversation and draft stay mounted through opening, closing, and resizing.

The full-page frame is removed. Chat uses 16px text on phones and 17px on desktop, with readable paragraph spacing. The input has its own full-width row above the controls. Conversation history has larger titles and an actions menu for renaming or deleting chats. Memory, Watch Plans, Collections, Curation and Connections open inside the agent through the workspace button.

Deleting saved chats now works. Encore previously sent a JSON content-type header with an empty DELETE body, which Fastify rejected with a Bad Request error before it reached the deletion handler. Requests now add that header when they include a body. Deleting the active or last conversation correctly selects another chat or creates a fresh one.

The normal mobile landing is Dashboard. Existing `/encore` and `/encore?view=plans` links open the agent over Dashboard. Home Screen launch links continue to work.

Use `ghcr.io/dgruhin-hrizn/aperture:latest`, or pin `ghcr.io/dgruhin-hrizn/aperture:1.0.3`, then recreate the app container and refresh the browser. No database migration is added.
