# v0.8.0-dev.7 — Floating mobile dock

A visual redesign of mobile navigation and Encore's canvas, based on dev.6.1.

## At a glance

| Area | Change |
| --- | --- |
| Navigation | Inset translucent capsule with a raised circular Encore action |
| Icons | Consistent line icons and a conversational Encore mark |
| Selection | Subtle icon/text emphasis with accessible current-page state |
| Encore | Continuous mobile canvas, tonal prompt cards and a compact rounded composer |
| Interaction | Safe-area spacing, landscape width cap, 44px targets and reduced-motion support |

## Summary for users

The five mobile destinations now sit in a floating dock. Encore stands above the capsule as the central conversation action, with a working indicator while it responds. The four surrounding destinations keep quiet labels. Encore's canvas flows into the dock area, and its composer uses a shorter mobile placeholder. Drafts and streaming continue across navigation.

## Summary for admins

Existing routes, Watching feature gates, saved appearance choices and action approvals remain authoritative. The dock uses the active theme's colours in light and dark modes. Desktop navigation retains its existing layout.

## Database migrations

None.

## API and operator notes

No API changes. The mobile pane's reserved navigation height follows the dock dimensions, keeping the composer and Media Graph clear of its raised centre action. No new runtime dependencies or image assets are required.

## Update instructions

Pull `ghcr.io/dgruhin-hrizn/aperture:0.8.0-dev.7` and recreate the app using the existing configuration, or use the development channel. Reload the browser or home-screen shortcut. Existing data and MCP credentials remain valid; the current bridge and checksum are attached.
