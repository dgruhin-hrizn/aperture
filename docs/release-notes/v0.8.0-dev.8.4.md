# v0.8.0-dev.8.4 — Encore tool cards on mobile

- Movie and TV details now put the poster beside the title and key information. Expand the synopsis and credits when you want to read more. Library titles use the same Play, Details, rating, and playlist or Watching controls as search results.
- Swipeable media results use shorter cards on phones. Release dates, episode runtimes, and source links fit into compact rows. Filmography links have larger tap targets.
- Genre breakdowns, franchise progress, streaming providers, viewing statistics, and help use less vertical space. Longer lists in those cards and in watch plans, collection proposals, and curation results can expand inline.
- Approval, calendar export, and curation controls stay available while long previews are collapsed. Tool feedback and web citations are easier to scan and tap.

Pull `ghcr.io/dgruhin-hrizn/aperture:0.8.0-dev.8.4` or refresh the development image and recreate the app container. No database migration is required.
