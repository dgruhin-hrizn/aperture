# v0.8.0-dev.6.1 — Mobile sheet touch targets

A usability patch for the mobile Encore shell in dev.6.

## At a glance

| Area | Change |
| --- | --- |
| History and dialogs | Buttons retain a minimum 44px touch target inside portalled sheets |
| Lists | Mobile list actions also retain a minimum 44px height |

## Summary for users

Conversation rename/delete controls, history close buttons and dialog actions are easier to tap on a phone. The larger mobile control sizes now cover sheets as well as the main screen.

## Summary for admins

The mobile-only styles include portalled controls. Desktop dimensions and existing authorization rules continue to apply.

## Database migrations

None.

## API and operator notes

No API changes. See the [mobile guide](../mobile-app.md) and [dev.6 notes](v0.8.0-dev.6.md) for the complete mobile shell.

## Update instructions

Pull `ghcr.io/dgruhin-hrizn/aperture:0.8.0-dev.6.1` and recreate the app with your existing configuration, or use the development channel. Reload the browser. Existing data and MCP credentials remain valid; the current bridge and checksum are attached.

## Validation and changelog

- Include portalled dialogs and sheets in mobile button sizing, and apply minimum height to mobile list actions.
- Lint/type checks, production build and mobile regression checks.
- Real-app browser checks of history-sheet rename/delete, close and list action dimensions.
