# v0.8.0-dev.8.1 — Encore title search and compact mobile results

Encore can find a title when you leave out a leading article or make a small typo. “Housemaid” and “Housemaids” can both find “The Housemaid” in your library. Exact and close matches in the title or original title appear ahead of synopsis matches. Library access and search filters still apply.

Title lookup uses PostgreSQL’s existing trigram support and works without an embedding provider. Encore uses semantic search for descriptions of plots, themes, and moods.

A single movie or series result now fills the chat width on phones, with the poster beside the title, metadata, and Play button. Multiple results still scroll horizontally.

Pull `ghcr.io/dgruhin-hrizn/aperture:0.8.0-dev.8.1` or refresh the development image, then recreate the app container with the existing configuration. This release requires no database migration.
