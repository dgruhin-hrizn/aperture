# v0.8.0-dev.5.1 — Watch-plan editor feedback

Includes all four Encore stages from dev.5 and a small interface correction: failed plan edits now display their error inside the open editor. Users can see validation, availability and permission failures immediately, correct their inputs and retry. Opening or retrying clears the previous editor error.

No database or behavior migration is added. Lint/type checks and production builds pass; the release pipeline runs the full Encore and application regressions. The error interface is verified in the isolated browser preview. Use `ghcr.io/dgruhin-hrizn/aperture:0.8.0-dev.5.1` or the development channel. Stable `latest` remains unchanged.
