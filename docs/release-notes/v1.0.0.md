# Aperture 1.0.0

Aperture 1.0.0 brings the Encore workspace, the mobile app layout, Play Iris branding, and the recommendation and performance work from the development series to the stable channel. The previous stable version was 0.7.10.

## At a glance

| Area | What shipped |
| --- | --- |
| Encore | A persistent media consultant with conversation history, watch plans, editable memory, collections, and opt-in recurring curation. |
| Mobile | A floating navigation dock, keyboard-aware composer, and standalone Home Screen launch into Encore. |
| Play Iris | A new Aperture mark in the app, API documentation, fallback artwork, and Home Screen icons. |
| Recommendations | Freshness controls, optional Emby publishing modes, and Tonight picks with temporary snoozes. |
| Discovery and appearance | Faster Discovery and People reads, progressive upcoming episodes, and the optional Studio light and dark theme. |
| Administration | Scoped MCP connections, tighter runtime API validation, and a media import job that runs independently of AI generation. |

## Summary for users

- The mobile layout refresh brings results closer to the top of Discover, Library, history, and Top Picks. The shorter header and dock leave more room for content. Title details put the poster beside the title, requests fit the phone width, and setup shows the current step with a progress bar.
- Encore can consult your accessible library and viewing history, find releases, and help assemble a watch plan. Manage its saved memory, plans, collections, and connections from the workspace. Web search and recurring curation are opt-in. [Encore documentation](https://github.com/dgruhin-hrizn/aperture/blob/v1.0.0/docs/encore-rebuild.md)
- Open Aperture from your Home Screen to launch Encore in standalone mode. The mobile dock keeps Discover, Library, Encore, Watching, and You within reach. Play Iris is used for the installed icon. [Mobile app documentation](https://github.com/dgruhin-hrizn/aperture/blob/v1.0.0/docs/mobile-app.md)
- Choose Studio under **Avatar → Appearance** for a light, dark, or device-following theme. Discovery rows and People portraits load progressively, and Emby users can snooze a Tonight pick for 12 hours. [Appearance settings](https://github.com/dgruhin-hrizn/aperture/blob/v1.0.0/docs/features/user-settings/appearance.md)

## Summary for admins

- Configure recommendation outputs independently for movies and TV. Emby supports named TV groups, private native playlists where supported, and pinning Aperture-managed playlists to Home. **Import Media Server** syncs catalog and history without generating AI recommendations. [Output configuration](https://github.com/dgruhin-hrizn/aperture/blob/v1.0.0/docs/admin/output-format.md)
- Create individually scoped, revocable MCP connections from Encore. Playlist actions require approval, and recurring curation runs only after explicit opt-in. [MCP setup and permissions](https://github.com/dgruhin-hrizn/aperture/blob/v1.0.0/docs/encore-mcp.md)

## Database migrations

Upgrades from 0.7.10 apply migrations **0115–0123**. These add recommendation suggestion history, Emby groups and managed playlists, Tonight snoozes, and storage for Encore messages, scoped connections, memory, plans, actions, and recurring curation. The suggestion-history migration backfills retained completed runs, and the Encore message migration assigns stable keys to existing messages.

The supplied production Compose files apply pending migrations at startup and continue to use PostgreSQL 16 with pgvector. Back up the database and uploaded artwork before updating.

## API and operator notes

- `GET /health`, OpenAPI, and the web app report **1.0.0**.
- The scoped Encore MCP endpoint uses Streamable HTTP at `/mcp`. The release also includes the standalone `aperture-mcp.mjs` bridge and its SHA-256 checksum for local stdio clients. [MCP connection instructions](https://github.com/dgruhin-hrizn/aperture/blob/v1.0.0/docs/encore-mcp.md)

## Update instructions

The stable image is `ghcr.io/dgruhin-hrizn/aperture:latest`. Pin `ghcr.io/dgruhin-hrizn/aperture:1.0.0` to keep this version.

1. Back up PostgreSQL and uploaded artwork. Keep the existing database and mounts.
2. From the directory containing your production Compose file, pull and restart Aperture.

   ```bash
   docker compose pull
   docker compose up -d
   ```

3. Confirm the startup log shows successful migrations and `/health` reports **1.0.0**. Sign in and check Encore and your configured recommendation outputs.
