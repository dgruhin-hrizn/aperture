# v0.7.11-dev.9 — Studio light detail-dialog fix

This development release fixes the external-title details dialog used by Gap Analysis and other TMDb-only views.

- Studio light uses solid light content panels and a pale artwork overlay, keeping the title, synopsis, metadata, director and cast readable.
- Chips and hover states follow the light palette. Studio dark and Classic keep their existing dark overlays.
- Trailer, Request, TMDb/IMDb links and cast/director navigation remain available. The close button has a translated accessible label.

No new settings, migrations, recommendation changes or preference resets are included. The existing algorithm review remains separate development work.

Use `ghcr.io/dgruhin-hrizn/aperture:dev` to receive this build. The fixed build is also available as `:0.7.11-dev.9`; `:latest` remains the stable release.

Validation: Studio light, Studio dark and Classic were inspected in an isolated browser fixture. Seven appearance compatibility/preference tests and repository lint, builds and type checks passed. Fixture data omits images and cannot make real media-server, request or AI calls. Deployment verification is recorded separately.
