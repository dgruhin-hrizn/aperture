# Aperture 1.0.1-dev.3

This development release reduces the load Aperture places on Emby when publishing recommendation libraries. Repeated library rebuilds were followed by large numbers of media probes and stalled browsing requests in an affected installation. These changes address that workload; they do not establish the exact cause of Emby's internal stall.

Movie and TV library publishing now prepares authorized output outside Emby's watched folders and reconciles it with the current library. Unchanged media symlinks, episode metadata, sidecars, and artwork keep their identities and timestamps. Revoked or stale files are removed, and failed access verification still withholds output. Metadata dates follow the recommendation run rather than the time of each sync.

Unchanged libraries skip refresh requests. Pending refreshes survive failed submissions so a later sync can retry. Changed libraries share a paced refresh queue, respect active refresh status when Emby reports it, and back off after a failure. Aperture disables automatic monitoring and duplicate thumbnail/marker extraction only on its managed recommendation libraries, using targeted refreshes for published changes. Source-library settings are preserved.

Emby-heavy background jobs run one at a time. Emby provider requests share a four-request limit, and request timeouts cover the response body as well as the initial connection. Unchanged artwork is reused for up to 24 hours, and image download batches are smaller and have timeouts.

Migration `0126_stagger_media_jobs.sql` restores staggered minute offsets for legacy interval schedules whose offsets were unset. Explicit administrator schedules, including minute zero, are preserved. New default watch-history and watching/favorites jobs are also staggered.

The development image is `ghcr.io/dgruhin-hrizn/aperture:1.0.1-dev.3`, also published as `:dev` after both architectures pass their image smoke tests. The first sync may update metadata dates and library options; subsequent unchanged syncs avoid those file changes and scans.
