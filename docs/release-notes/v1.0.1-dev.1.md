# Aperture 1.0.1-dev.1

This development release builds on 1.0.0 with Encore response styles and an updated AI cost estimator.

## At a glance

| Area | What changed |
| --- | --- |
| Encore | Choose Quick, Standard, or Expanded for the next reply. |
| Compatibility | Supported models use native reasoning controls. Older and local models use response instructions and tool limits. |
| AI settings | Set the chat default and test the selected model configuration. |
| Cost estimates | Compare Encore styles with published model prices and recent measured token usage. |

## Summary for users

- **Quick** keeps routine questions and library lookups short. **Standard** suits everyday conversations. **Expanded** gives complex comparisons and watch plans more room.
- A reply-specific choice resets after sending. Encore keeps provider reasoning and continuation data separate from the visible conversation.
- When a provider reaches its output limit, Encore explains the limit and offers a retry.

## Summary for admins

- Set the default response style in **Admin → Settings → AI / LLM**. Text generation and Exploration expose settings when the selected model supports effort controls.
- The estimator uses published standard OpenAI rates for supported models, including discounted cached input. Reasoning tokens are included in output charges. Encore's per-style estimates use the past 30 days of measured usage when available.
- Unraid testing covered five OpenAI models, with 41 of 45 checks passing at an estimated cost of $0.049. Standard and Expanded both passed the hardest watch-planning task on Luna, Terra, and Sol. Quick passed that task on Sol. The individual results are small samples.

## Database migrations

Migrations **0124–0125** separate provider continuation data from the visible transcript and create daily usage aggregates. The aggregates contain token counts and sample totals without conversation or user identifiers. The supplied production Compose configurations apply pending migrations at startup.

## API and operator notes

- The app, health endpoint, OpenAPI, and MCP bridge report **1.0.1-dev.1**.
- Encore accepts a reply-specific preset. The admin pricing endpoint includes the available model rates and the measured usage behind the estimate.
- The release includes the standalone MCP stdio bridge and its SHA-256 checksum.

## Update instructions

Back up PostgreSQL and uploaded artwork. Set the Aperture image to `ghcr.io/dgruhin-hrizn/aperture:1.0.1-dev.1` or use the development channel at `ghcr.io/dgruhin-hrizn/aperture:dev`, then pull and recreate the app container.

```bash
docker compose pull
docker compose up -d
```

Check that `/health` reports **1.0.1-dev.1**, then verify your configured model in AI Settings and send a reply from Encore.
