# Aperture 1.0.2-dev.2

Includes the STRM/symlink guidance, output compatibility checks and documentation refresh from dev.1, with a correction found during live verification.

The temporary output-check directory now uses the same creation permissions as normal published output. Previously it was private to Aperture's user, so Emby running under another account could report a path-check warning even though the generated-library storage was compatible. The check still removes its temporary files and leaves playback explicitly unverified.

Regression coverage now checks that the temporary directory and marker allow a separate media-server account to traverse and read them under normal publication permissions. Required failures, unsupported automatic checks, and optional source access remain distinct.

Use `ghcr.io/dgruhin-hrizn/aperture:1.0.2-dev.2` or `:dev` after publication. Stable `:latest` remains 1.0.1. Pull and recreate the app with existing mounts, refresh the page, and rerun **Check output compatibility**. No migration or automatic format change is added.

See the [dev.1 notes](v1.0.2-dev.1.md) and [documentation review](../documentation-review.md) for the complete UI and documentation changes. Shared guidance is initially in English pending localization.
