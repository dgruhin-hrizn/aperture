# v0.8.0-dev.8.3 — Live AI model lists and smoother Encore release lookups

OpenAI model pickers now query the provider with the configured key. Available models appear for each feature, and the installed configuration keeps its selected model until you save a change. Aperture uses the bundled list if it cannot reach the OpenAI catalog.

For a local server such as oMLX, open **Admin → Settings → AI & LLM → Chat Assistant**. Choose **OpenAI-Compatible**, enter the server URL and API key if required, then select **Refresh models**. Choose a model, select **Test**, and save it. Chat checks that the selected model can stream a valid tool call. The picker uses model types when the server reports them. Embeddings use the existing dimension setup.

Encore now understands relative release windows such as “next few weeks,” which covers today through 14 days ahead in your timezone. The results show the dates checked. The regional TV calendar covers up to seven dates, while movies and episodes for followed shows can use a longer window. Release cards show five results initially and can expand to the full list.

Pull `ghcr.io/dgruhin-hrizn/aperture:0.8.0-dev.8.3` or refresh the development image and recreate the app container. No database migration is required.
