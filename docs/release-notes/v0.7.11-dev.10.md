# v0.7.11-dev.10 — Faster Discover

Changes since dev.9:

- Discover shows saved suggestions without waiting for Seerr availability and request badges. A slow or unavailable Seerr no longer keeps the list on skeletons.
- Only the selected popular Movies or Series list loads. Genre and Streaming views avoid fetching hidden popular lists.
- Repeated Seerr lookups share a short cache, reuse batch configuration and run with bounded concurrency and deadlines. Submitting or cancelling a request invalidates cached statuses. Movie and TV IDs are handled separately.
- Visible genre and streaming rows can load two at a time. Configuration/labels and raw genre pages are reused, and changing sections cancels obsolete work.
- Idle job monitoring uses one check a minute and pauses while hidden; running jobs keep live progress.
- Saved-list caches are scoped to users and filters and revalidated against current server permissions and library exclusions before display.

No new settings, migrations, recommendation-score changes or preference resets. Existing Classic/Studio, light/dark and all admin/user settings remain unchanged by the update.

Use `ghcr.io/dgruhin-hrizn/aperture:dev` to get this development release, or pin `:0.7.11-dev.10`. `:latest` remains the stable channel.

See [Discover performance documentation](../discovery-performance.md) for cache lifetimes, failure behavior, measurements and validation details.
