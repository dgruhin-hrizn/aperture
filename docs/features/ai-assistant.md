# Encore

Encore is Aperture's media assistant and workspace. Open **Encore** from navigation. On phones, the center dock button opens Encore; Home Screen launches also open its standalone workspace where supported.

## Start with a question

Ask for a movie you only partly remember, an unwatched film under 90 minutes, a director's work, or upcoming episodes of a followed series. Library searches respect current media-server access. Results distinguish playable library items from external discoveries and release forecasts.

Choose **Quick**, **Standard**, or **Expanded** beside the composer for one reply. Admins configure the default and provider under **Settings → AI / LLM**. Availability of web search and other tools depends on that configuration. Web search starts off and can add provider charges.

## Conversations and actions

Saved conversations retain their messages and context. You can rename or delete them, stop a response, retry a failed reply and use editable suggested follow-ups. Browse other pages while Encore works and return to the conversation.

Movie and TV cards can open details or playback, record ratings, and manage Watching where available. Private Emby playlist and Home actions show proposed changes for approval. Playback uses the supported media-server/client route; it is not a separate video player inside Encore.

## Memory, plans and connections

Inspect, correct, expire or forget saved Memory. Lasting preferences can inform your Taste Profile; temporary constraints can expire. Watch Plans use your available windows, timezone, runtimes, episode order and viewing progress. Review, edit, save or export a plan as a calendar file.

Collections and Recurring Curation manage supported private Emby playlists. Recurring rules start paused and require opt-in. Connections create individually scoped and revocable MCP access for external clients. These capabilities do not bypass library permissions.
