# Appearance

Open your avatar menu → **Appearance**, or **Settings → Preferences → Appearance**.

- **Classic** preserves Aperture’s original dark appearance. It remains the default for accounts that have not chosen a theme.
- **Studio** adds cobalt accents, Manrope typography, clearer surfaces and borders, and updated navigation styling. It supports **Light**, **Dark**, and **Follow device**.
- **Follow device** updates Studio when your device changes between light and dark appearance.

Choose a theme and color mode, then click **Save appearance**. Your choice belongs to your Aperture account and follows you when you sign in on another device. Other users choose independently. Studio also provides a sun/moon button beside search for saving a quick light/dark change. To resume automatic switching after using that button, choose **Follow device** again in Appearance.

You can select **Classic** and save at any time. Classic always uses its original dark palette; Aperture remembers your Studio color mode for when you switch back. Signing out returns the sign-in screen to Classic, rather than carrying another account’s personal appearance onto a shared device.

## What changes

Studio styles the existing application: Dashboard, Tonight, Recommendations, Shows You Watch, Top Picks, Playlists, Media Graph, Discover, Requests, Browse, History, Stats, media/person/studio details, user settings, admin pages, setup, search, dialogs, and the assistant. All existing navigation entries, permissions, feature flags, filters, actions, ratings, graph controls, and grid/list preferences remain available. Posters, artwork overlays, source badges, and categorical chart colors retain their meaning.

This is a visual theme, not the reduced functionality of the earlier design mockup. Existing page layouts and working controls remain in place.

## What stays separate

Appearance does not change recommendation weights, cooldowns, viewing history, ratings, source access, playlists, generated library names, Emby Home sections, jobs, credentials, or administrator configuration. Choosing a theme does not run a job or contact Emby. Existing settings are not migrated or reset.

If loading the preference fails, Aperture uses Classic and provides **Retry** before allowing a new choice. If saving fails, the previously active appearance remains in place and an error is shown. The new labels are available in all supported interface languages, including right-to-left locales.
